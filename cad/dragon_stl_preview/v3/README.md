Units: millimetres. This is an improved faceted visual concept assembled from mesh primitives, not validated engineering CAD. The parts are not yet checked for watertightness, servo DS3225 mounting, fastening, wall thickness, moving-joint clearances, balance or collisions. Do not treat these files as print-ready functional parts; inspect and validate them in a slicer/CAD tool first.
