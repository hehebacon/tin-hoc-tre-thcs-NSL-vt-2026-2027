# XZORT DRAGON RESCUE QUADRUPED — V4 angular concept meshes

V4 replaces the rounded gecko-like V3 silhouette with angular layered armor plates, a horned head, dorsal armor/spines, segmented tapering tail, and four armored legs.

Files (units mm):
- head_shell_v4.stl
- back_armor_v4.stl
- tail_shell_v4.stl
- leg_armor_v4.stl
- assembly_concept_v4.stl

This is a visual concept mesh set inspired by the approved reference image, not a pixel-identical reconstruction or print-ready mechanism. The image does not provide source CAD geometry. Before functional printing, split parts into printable shells and validate watertightness, dimensions, wall thickness, DS3225 mounting, fasteners, joint travel, balance, collision clearance, and electronics access. Overall design target remains 350 x 350 x 350 mm; tail/head reach may exceed a 350 mm bounding box in the concept assembly and must be scaled/positioned in CAD before release.
