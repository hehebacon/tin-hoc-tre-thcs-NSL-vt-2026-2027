# XZORT Dragon V5 — print assemblies

Use the files prefixed `PRINT_` when you want the complete module in one slicer import.

- `PRINT_dragon_head_complete_v5.stl`: skull armor + horns/crown/cheek blades + lower jaw in one STL file.
- `PRINT_dragon_spine_armor_complete_v5.stl`: spine base + dorsal and side spikes in one STL file.

The original component STLs remain for editing only. Import the PRINT file as a single model. Note: a single STL can contain multiple intersecting/overlapping shells; this is one-file packaging, not proof of a watertight Boolean union. Inspect/repair in your slicer and verify orientation, dimensions, and bed fit before printing. These are still concept geometry and are not mechanically validated for final assembly.
