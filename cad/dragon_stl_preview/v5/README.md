# XZORT Dragon Module V5 — STL Preview

This folder contains the first detailed-form pass for the dragon head and dorsal spine modules.

## Files
- `dragon_head_armor_v5.stl` — tapered multi-profile skull, swept horns, brow/crown spikes and cheek blades.
- `dragon_lower_jaw_v5.stl` — separate lower jaw/chin module.
- `dragon_dorsal_spines_v5.stl` — curved spine base with alternating dorsal and lateral blades.

## Coordinate / scale
- Units: millimetres (STL convention; import at 1:1).
- Head runs along +X toward the snout.
- These are visual/mechanical concept meshes, not yet validated for servo clearances, screw bosses, wall thickness, watertightness, or collision fit with the existing chassis.
- Before printing functional parts, run a mesh repair/check and confirm the assembly dimensions against the 350 mm envelope. Do not treat this preview as a fit-verified final part.
